## Overview

**AETERNUM** is an interactive web experience and visual essay designed to blend editorial storytelling with kinetic web choreography. Built as a contemplative digital space, the project pairs atmospheric visuals, expressive typography, and scroll-driven motion to examine fundamental questions of existence.

> *"What endures when time strips away everything else?"*

---

## Core Themes

The narrative structure of AETERNUM is anchored around five philosophical pillars:

| Pillar | Exploration |
| :--- | :--- |
| **Identity** | The tension between who we are, who we perform to be, and what remains beneath external perception. |
| **Suffering** | Endurance, grief, and the quiet transformation forged through inevitable struggle. |
| **Legacy** | The imprint left behind—memories, works, and echoes that outlive their creators. |
| **Ambition** | The relentless drive to transcend limits, and the unseen cost of reaching higher. |
| **Morality** | Conscience, accountability, and the weight of choices made in moral ambiguity. |

---

## Key Features

- **Visual Essay Experience** — Structured narrative pacing combining curated imagery, editorial typography, and atmospheric contrast.
- **Fluid Motion Choreography** — Smooth entrance sequences, micro-interactions, and scroll-linked transitions powered by **Motion**.
- **Responsive Editorial Layout** — Precision-crafted grid and fluid scaling across desktop, tablet, and mobile viewports using **Tailwind CSS**.
- **Modular Component Architecture** — Clean, maintainable, and strictly typed codebase built with **React** and **TypeScript**.

- **Core:** React, TypeScript

## Getting Started

### Prerequisites

Make sure you have **Node.js** (v18+) and **pnpm** (or `npm` / `yarn`) installed on your machine.

### Installation

1. **Clone the repository**
   ```bash
   git clone [https://github.com/Wikan-dev/aeternum.git](https://github.com/Wikan-dev/aeternum.git)
   cd aeternum
   ```

2. **Install dependencies**
   ```bash
   pnpm install
   ```

3. **Start the development server**
   ```bash
   pnpm dev
   ```

4. **Build for production**
   ```bash
   pnpm build
   ```
